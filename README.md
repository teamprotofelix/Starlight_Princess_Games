# 별빛 공녀 — 운명의 여덟 해
## SPRITE THEATRE EDITION v3.0 · 2026-10-21

고전 육성 시뮬레이션에서 영감을 받아 새로 구현한 **비공식 독립 창작 오프라인 Chrome 게임**입니다. 상용 원작의 소스, 실행파일, 이미지, 음악을 포함하지 않습니다.

### 시작하기

1. 이 ZIP을 하나의 폴더에 **전부 압축 해제**합니다.
2. **`index.html`을 Chrome에서 엽니다.** 별도의 서버·계정·인터넷 연결·설치는 필요하지 않습니다.
3. `새로운 이야기` → 공녀 이름·난이도 선택 → 좌측 메뉴 또는 하단 카드에서 교육/일/휴식 등 선택.
4. 일정 계획에서 **첫째·둘째·셋째 열흘**에 각각 활동을 배치하고 `이번 달 진행`을 누릅니다.
5. 세 가지 활동이 **각각 움직이는 스프라이트 무대**에서 순서대로 재생됩니다. 이후 월간 결과를 확인할 수 있습니다.

### v3.0 핵심 변화 — 실제로 움직이는 행동

- **10종 × 8프레임의 WebP 스프라이트 시트 추가**: `idle`, `walk`, `write`, `work`, `sword`, `dance`, `cast`, `rest`, `pray`, `cook`.
- 기존 실사풍 캐스팅 캐릭터 포즈를 이용해 **40~80초짜리 동영상이 아닌, 브라우저에서 연속 반복되는 프레임 애니메이션**을 제작했습니다.
- 월간 일정 3구간이 **각기 다른 배경, 행동, 소품, 걸음·필기·검술·춤 등 동작과 빛/음표/입자 이펙트**로 재생됩니다.
- 동일 일정이라도 화면 장식·동작 타이밍이 달라지며, 캐릭터를 눌러 응원 반응을 볼 수 있습니다.
- **일시정지 / 2배속 / 다음 구간 / 전체 건너뛰기**를 지원합니다. 일반 재생은 구간당 약 4초입니다.
- 외출·구매·아이템 사용·궁정 알현·가족 대화·사건 선택·수확제에도 짧은 연출이 적용됩니다.
- 전투 대화상자는 정지된 캐릭터 대신 **8프레임 전투 스프라이트와 공격·피격 동작**을 사용합니다.
- v2의 실사 배경, 금장 HUD, 그림형 행동 카드, 27개 개별 활동 카드와 월간 3컷 결과 화면을 유지했습니다.

> **기술 설명:** 여러 포즈에서 파생한 2D 스프라이트 시트를 CSS `steps(8)`으로 전환하면서 위치·기울기·소품·입자 효과를 애니메이션합니다. 실제 3D 캐릭터의 관절 애니메이션이나 동영상 풀모션은 아닙니다. 원본 사진 이미지 일부를 재활용하며, 행동별 전문 애니메이션 컷을 개별 신규 생성한 것은 아닙니다.

### 기존 육성 콘텐츠 (동일)

- 10세부터 18세까지 총 **96개월**, 3구간 일정, 12개 교육 / 12개 아르바이트 / 2개 휴식 / 1개 탐험
- 신체·지능·교양·전투·마법·명성·스트레스·생활비 관리
- 4개 탐험 지역, 턴제 전투, 연례 수확제 4개 부문, 궁정 6명과 관계
- 왕도 상점, 장비, 이야기 분기, 총 22개 직업 엔딩
- 자동 저장·슬롯 3개·JSON 파일 내보내기/불러오기

### 저장 데이터

기존 v1/v2의 localStorage 키 `starlight-princess-save-v1`을 그대로 사용하므로, **같은 Chrome 프로필/원본 URL로 게임을 열 경우 기존 저장 데이터를 이어서 사용할 수 있습니다.** 폴더 경로나 파일 URL이 달라지면 Chrome이 별도 저장 출처로 취급할 수 있으니, 이전 버전의 `저장 → JSON 내보내기` 기능으로 백업한 뒤 v3에서 가져오는 방법이 안전합니다.

### 2026-10-31 안정성 보완

- 활동 연출 중 배경 화면을 `inert`로 격리하고 키보드 초점을 연출 내부에 유지합니다. 종료하면 기존 입력 상태를 복원합니다.
- 손상된 저장 파일의 일정·능력치·궁정·소지품·기록을 불러오기 전에 검사합니다. 실패하면 현재 진행을 유지합니다.
- 가져온 기록과 엔딩의 문자열을 HTML 대신 텍스트로 표시합니다.
- `tests/review.cjs`로 새 게임, 구버전 저장 호환, 잘못된 파일 가져오기, 재생 조작, 입력 격리, 27개 활동 이미지, 전체 96개월, 수확제 8회, 탐험 연속 전투, PC/모바일을 재검증했습니다. JS 예외 및 이미지 요청 실패 0건입니다.
- 회귀 검사: Playwright를 개발 환경에 설치한 후 `node tests/review.cjs`를 실행합니다. 필요하면 `CHROMIUM_PATH`와 `PLAYWRIGHT_MODULE_PATH`로 실행 환경을 지정합니다. 검사 전용 훅은 로컬 테스트 서버에서만 삽입되며 게임 코드에는 포함되지 않습니다.

### 파일 안내

- `index.html` : 게임 화면 시작점
- `game.js` : 게임 시스템·수치·이벤트·전투·기존 저장

- `assets/sprites/*.webp` : 10개 8프레임(가로 배열) 스프라이트 시트

### 아트 및 연령 안내

게임상 육성 나이는 10~18세이지만 실사풍 캐릭터 이미지는 **성인 배우가 연기하는 판타지 캐스팅 포스터와 같은 상징적 연출**이며, 나이에 따른 실제 외형 표현을 의도하지 않습니다. 기존 캐릭터 이미지를 기반으로 파생 스프라이트를 만들었습니다.
