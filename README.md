# 별빛 공녀 — 운명의 여덟 해

## CINEMATIC EDITION v2.0 (2026-10-21)

고전 육성 시뮬레이션의 매력을 기리는 **비공식 독립 창작 HTML/JavaScript 오프라인 웹게임**입니다. 10~18세, 8년 동안 선택이 누적되어 여러 진로로 이어집니다. 상용 원작 게임의 실행 파일, CG, 음악, 소스 코드가 아닙니다.

### 바로 실행
1. ZIP 전체를 한 폴더에 압축 해제합니다.
2. `index.html`을 Chrome에서 엽니다. 별도 서버·인터넷·계정·설치가 필요 없습니다.
3. **새로운 이야기**를 선택하고 이름과 난이도를 정합니다.
4. 메인 화면의 그림 카드(교육·일·외출·사교·모험·휴식)나 좌측 메뉴에서 활동을 고릅니다.
5. 활동 카드로 이번 달의 첫째·둘째·셋째 열흘을 채운 다음 우측 **이번 달 진행**을 누릅니다.

> 파일을 옮길 때 `index.html`만 복사하면 안 됩니다. `style.css`, `game.js`, `assets/` 폴더를 함께 유지하세요.

### v2.0에서 달라진 점
- 풀사이즈 **왕궁 침실 씬과 대형 실사풍 캐릭터**, 테마에 따른 장소 배경 전환
- **그림형 6개 주요 행동 카드** + 사진이 들어간 좌측 탐색 메뉴
- 체력·지능·기품 등 상태 막대가 표시되는 금장 HUD, 3구간 일정 썸네일, HUD에서 월 진행
- **27개의 개별 활동 일러스트 WebP** + 여러 장면의 합성·크롭·재활용 이미지
- 월말 **3컷 시네마틱 추억 화면**과 선택 결과, 임금·교육비·능력치 변화 표시
- 교육과 일자리, 왕도 상점, 모험, 수확제, 이야기, 엔딩 등 상세 화면의 실사 이미지 면적 확대
- 데스크톱/모바일 레이아웃 조정, Hover/전환/모달 애니메이션 및 사진 중심 지도 카드
- 기존 v1 저장 키(`starlight-princess-save-v1`) 유지 — 기존 진행 이어하기 지원

### 수록된 주요 게임 시스템 (v1 유지)
- 96개월 × 월간 3구간 일정, 총 27종 행동(교육 12, 일자리 12, 휴식 2, 탐험 1)
- 재정·체력·스트레스·도덕성·신앙·매력·마법·전투·예술·생활기술 및 명성
- 왕도 쇼핑과 아이템·장비, 궁정 관계 6명, 가족 대화와 유대감, 이야기 선택지
- 모험 지역 4개, 턴제 전투(검 공격·마법·방어·대화·영약·도주)
- 매년 수확제: 무술·무도회·요리·예술의 네 부문
- 22가지 진로 엔딩, 3개 수동 저장 슬롯, 자동 저장, JSON 저장 내보내기/불러오기

### 이미지 자산
모든 이미지 자산은 **WebP**입니다. 인물 스프라이트·장소 배경 12종의 초기 소재에 더하여 **행동 27장, 도크 8장, 장면 8장**을 추가하여 총 55장입니다. 사진형 카드와 장면 이미지는 생성된 캐릭터/배경을 추가 편집·합성한 이미지이며, 상용 원작 CG가 아닙니다. 이미지 크기를 키우기만 한 것이 아니라, 게임 UI 내부의 실제 표시 면적도 크게 변경했습니다. 다만 새로 합성된 이미지는 서로 같은 캐릭터와 배경 원본을 공유합니다.

**연령 안내:** 게임의 10~18세는 수치로 표현되는 육성 나이이며, 실사풍 성인 캐릭터 이미지들은 연령별 성장 사진을 의미하지 않는 **상징적인 캐스팅 비주얼**입니다.

### 중요 사용 팁
- 상단의 저장 아이콘 → 슬롯 저장 또는 JSON 내보내기를 권장합니다. Chrome의 `file://` 환경에서 저장 정책은 프로필·브라우저 설정에 따라 달라질 수 있습니다.
- 교육비와 생활비가 부족하면 임금이 있는 일부터 계획하세요. 스트레스가 쌓이면 휴식 카드로 구간을 배치하세요.
- **12세부터 탐험**을 진행할 수 있습니다. 해당 화면에서 지역을 지정한 후 탐험 일정을 넣으세요.
- 매년 10월은 수확제가 개최되며 월간 계획 대신 대회에 출전합니다.
- 메인 화면으로 돌아가려면 상세 화면 상단의 **↑ 공녀의 방으로**를 누릅니다.

- Node.js `--check` 문법 검증 성공.
- Chromium `set_content` 기반 UI 검사: PC 1600px, 모바일 390px, 교육 선택·월간 진행 성공, 실행 예외 0건.
- 월간 96턴 연속 플레이/수확제 8회/18세 엔딩 도달 확인.
- 현재 테스트 실행 환경에서는 브라우저가 로컬 파일 및 로컬 서버 탐색을 관리자 정책으로 차단했습니다. **Windows Chrome에서 `file://` 경로를 직접 여는 실기기 테스트는 완료하지 못했습니다.** 직접 실행 중 이상이 발생하면 JSON 백업을 확보하고 오류 화면을 전달해 주세요.
- 아직 원작의 모든 스토리·정확한 공식·경연과 탐험의 세부 리얼타임 애니메이션·모든 연령별 독립 인물 사진·게임 음성·풀 OST 등은 재현되지 않았습니다.
